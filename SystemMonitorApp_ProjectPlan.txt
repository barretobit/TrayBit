TrayBit - Current Scope
======================

TrayBit is a lightweight Windows system tray app with two features:

1. Show the CPU temperature and refresh it every second.
2. Display the selected Windows energy profile.

Temperature is read through LibreHardwareMonitor. TrayBit displays the CPU
temperature only. The tray tooltip shows the temperature and active energy
profile (for example, "29°C | Balanced"). If no CPU sensor or active profile
is available, the UI displays "N/A" or "Unknown", respectively.

Profiles are discovered from Windows, so all installed profiles are available.
The tray context menu provides profile selection and Exit.

Technology:
- C# / WinForms on .NET 10 for Windows
- LibreHardwareMonitorLib for temperature sensors
- Windows power APIs for enumerating and activating energy profiles
